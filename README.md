# Fashion Store

A modern, minimalist fashion e-commerce website built with HTML5 and CSS3.

## Live Demo

[View Live Website](https://zi2001djru.github.io/fashion-store/)

## About the Project

Fashion Store is a modern e-commerce website concept designed to showcase fashion collections through a clean, minimalist interface.

The project focuses on visual presentation, elegant typography, product layouts, and responsive design to provide a smooth browsing experience across different screen sizes.

## Features

- Modern minimalist design
- Responsive layouts for desktop, tablet, and mobile
- Fashion collection and product presentation
- Clean typography and structured layouts
- Carefully selected imagery
- Consistent visual design

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.

No build tools or additional dependencies are required.
